# Career Tools PWA

AI-powered career development platform with tools for resume optimization, cover letter generation, LinkedIn profile enhancement, and interview coaching.

## Features

- Resume Analyzer
- Cover Letter Generator
- LinkedIn Rewriter
- Interview Coach
- Career Roadmap
- Subscription & Pay-Per-Use Billing
- PWA (Progressive Web App)

## Getting Started

Visit [Career Tools](https://career-tools-pwa.vercel.app) to get started.

## Technology

- Frontend: React + TypeScript
- Backend: Express + Node.js
- Database: MongoDB
- Payment: Stripe
- Deployment: Vercel
